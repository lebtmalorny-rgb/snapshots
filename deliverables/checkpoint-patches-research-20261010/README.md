изменений к предоставленным форкам Nova/Cinder.

## Что реализовано

Nova: API и модель checkpoint, журналы операций, квоты и блокировки,
исполнитель сохранения RAM и восстановления через libvirt, координация Cinder.
Cinder: контракт операций над дисками, резервирование ресурсов, журнал,
сервисное продолжение операций и восстановление подключений томов.

Итоговые исходники Nova соответствуют tree
`5e968fbae851c47b321991e8cccd573b06e7e362`, Cinder —
`53888d9cea7fa1b12d35a0b9afd894eeee270843`.
Последовательность патчей проверена на исходных ZIP; результат записан в
[VERIFICATION.json](VERIFICATION.json).

Драйверы Huawei и YADRO TATLIN уже есть в исходном `cinder-pvs.zip`:
`cinder/volume/drivers/huawei/` и `cinder/volume/drivers/yadro/tatlin_*.py`.
Следующий этап — доработать их под checkpoint-контракт, используя имеющиеся
операции и добавляя недостающие гарантии; создавать весь драйвер с нуля
не требуется. В текущих версиях checkpoint-методы не переопределены,
поэтому наследуется базовый ответ `unsupported_driver`.

Функция выключена по умолчанию. Совместный откат реальных дисков и RAM не подтверждён.
Это результат разработки и исследования, а не готовое внедрение в OpenStack.

В прежнем полном комплекте основной объём занимали RAM-артефакты и данные
лабораторных прогонов. Здесь нет полных исходников, Git bundles, лаборатории,
Docker-образов, образов RAM и сырых логов. Тесты и документация, уже входящие
в продуктовые патчи, сохранены. Прежние большие архивы не изменены.
